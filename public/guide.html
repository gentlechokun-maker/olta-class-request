올타과학 운영 연결 안내

학부모는 GitHub Pages에서 수업을 확인하고 상담을 신청합니다. 신청 내역은 별도 비공개 Google 운영 문서에서 관리합니다.

현재 화면에 ‘미리보기’가 표시된다면 실제 접수 전입니다.
실제 반 설정, Google 서버 연결과 접수 확인을 마친 후 안내해 주세요.

1. 비공개 운영 문서 준비

새 Google 스프레드시트를 만들고 확장 프로그램 → Apps Script에서 저장소의 apps-script/ 파일을 추가하세요. setup을 실행하면 운영 표가 생성됩니다. 원본 공개 시간표에 신청 내역을 저장하지 마세요.

2. 시간표·운영 정보 입력

스크립트 속성에 원본 문서 ID, 탭 ID, 관리자 이메일과 공개 상담 연락처를 입력합니다. 반설정 표에서 반별 요일·시간·교실·담당 선생님·학생 이름 범위를 지정하세요.

원본 이름 글자색운영 기준
검정 · 확정 등록자리 차감
파랑 · 보강보강 날짜를 지정해 해당 날짜에 계산
녹색 · 상담 요청자리 차감 없음
보라 · 시작 예정자리 차감

한 셀의 이름별 글자색을 읽습니다. 모르는 색이나 메모가 있으면 자동으로 인원을 확정하지 않습니다. 실제 색상 코드와 판독 결과를 확인하세요.

3. Google 서버와 GitHub 연결

  1. Google Apps Script를 ‘본인으로 실행 / 모든 사용자 접근’ 웹앱으로 배포합니다.
  2. 생성된 /exec 주소를 public/config.js의 apiUrl에 입력합니다.
  3. GitHub 저장소 Settings → Pages → Source를 GitHub Actions로 지정합니다.
  4. 기본 브랜치에 업로드하고 Actions의 테스트·배포 성공을 확인합니다.
  5. 실제 신청과 관리자 확정을 확인한 뒤 네이버 공지에 공개 주소를 안내합니다.

4. 관리자 화면

비공개 운영 문서의 올타 상담 앱 → 관리 화면에서 상담 신청, 새 반 수요, 시간표 검토, 보강을 관리합니다. 공개 웹사이트에는 관리자 로그인 버튼이나 신청자 연락처를 노출하지 않습니다.
